# Kids Memory Match

**Game lineage:** Kids Memory Match SVG Game  
**Status:** canonical public source repository  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Kids Memory Match is a browser memory matching game for children. Players reveal visual pairs and remember their positions until every pair is matched.

## Lineage

This repository is the canonical public source for this game lineage.

The following public repositories are retained as earlier or duplicate development copies of the same game:

- `Joenasriani/kids-svg`
- `Joenasriani/kids-svg-game` (archived)

Historical names include **Kids SVG** and **Kids Memory Match SVG Game**. These names and repositories refer to the same underlying game lineage.

`Joenasriani/kids-memory-game` is a different game and must not be merged with this lineage.

## Technology

React browser application with a child focused memory matching interface.
